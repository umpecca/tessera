Tessera Clipboard Bridge

The optional Firefox extension enables text Copy/Paste commands in Tessera, including Firefox 115 ESR and HTTP connections. Keyboard paste continues to work without it.

Install a signed release

  1. In Tessera, open Settings → Clipboard. If the button says “Install Firefox extension”, click it and approve Firefox’s installation and clipboard permission prompts.
  2. If direct installation is blocked, save the XPI file. Open Firefox’s Add-ons Manager (about:addons), choose the gear menu → Install Add-on From File, and select it.
  3. Return to your Tessera tab. Open Tessera Clipboard Bridge from Firefox’s toolbar/extensions menu, enable this address, approve site access, and save.
  4. In Tessera Settings → Clipboard, click Check connection. It should say “Clipboard bridge connected”.

Unsigned development builds

If Settings says “Download development extension”, the package has not been signed by Mozilla and cannot be installed normally.

  1. Download the ZIP from Settings and extract it.
  2. Open about:debugging → This Firefox → Load Temporary Add-on. Select manifest.json in the extracted folder.
  3. Enable your Tessera address using the extension’s toolbar button, then check the connection in Tessera.

Temporary extensions are removed when Firefox closes. Reload the extension from about:debugging after changing its source, then refresh Tessera.

Permissions and clipboard behavior

Enable only addresses you trust. Authorization includes the exact scheme, hostname, and port. Firefox’s site permission prompt covers the hostname’s ports, but the bridge checks your exact approved address for every operation. Browser-pane frames and proxy pages are excluded.

Reads and ordinary writes require a recent click or key press in the Tessera page. There is no clipboard polling. The separate terminal option permits terminal programs to copy text without a click (OSC 52). It never permits terminal programs to read the clipboard. The bridge transfers plain text, limited to 1,048,576 UTF-16 code units per operation.

To revoke access, open the extension and remove the address. You can also remove the extension through Firefox’s Add-ons Manager. Settings status is refreshed by Check connection; blocked requests fall back to Tessera’s browser/internal clipboard behavior.

Updates

Updating Tessera does not update an installed extension automatically. When Tessera includes a newer signed package, Settings offers Update Firefox extension. Install it using the same flow and check the connection again. This extension has no automatic update URL.

If installation fails, verify that the package is signed, Firefox is at least version 115, and you are using the current maintenance update of Firefox 115 ESR.
